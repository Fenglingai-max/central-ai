# Central.ai 白色界面设计研究

研究日期：2026-10-29。依据用户新要求：简约白色、国际品牌网页感，保留双页创作流程。本文件仅为研究与执行建议，未修改代码。

## 一手来源与可迁移原则

## 白色体系的具体执行规范

以下数字是针对 Central.ai 的设计建议，**不是官网像素测量**。本环境的浏览器读取返回「No browser is available」，因此仅核验了官方内容与品牌规范，未声称完成网站截图或像素实测。

### 1. 颜色与层次

- 画布 `#FFFFFF`；分组底色 `#F7F7F6` 或 `#FAFAFA`，同一页面只保留一种。
- 标题和正文 `#18181B`；辅助说明 `#71717A`；真正禁用内容 `#A1A1AA`。
- 常规分隔 `#E7E7E8`，1px；输入边框 `#D7D7DA`。不要给所有分组加同等边框：页面分组依靠间距，只有输入、上传、选中状态和必要表格使用边线。
- 主按钮黑底白字；选中项目黑色细框 + 小勾，必要时浅灰底。只为运行状态保留一个低饱和绿点，不把每个模型供应商色铺成彩色大卡。
- 取消大面积紫色/荧光色、渐变光晕、玻璃模糊、装饰性噪点、厚阴影。图片自身保留色彩，周围 UI 保持中性。

### 2. 字体与比例

推荐 `Inter, -apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`。若不提供字体文件，准确称为系统字体方案，不能声称已经加载 Inter。

| 用途 | 桌面建议 | 移动建议 | 字重 / 字距 |
| --- | --- | --- | --- |
| 品牌字标 | 固定 24px 视觉高度附近 | 固定 22px | 预设 SVG，不随正文全局字距变化 |
| 页面主标题 | 48–56px / 1.12 | 32–36px / 1.18 | 500；英文 -0.035em，中文 -0.02em |
| 大标题下说明 | 16px / 1.65 | 15px / 1.6 | 400，正常字距 |
| 区块标题 | 18px / 1.4 | 17px / 1.4 | 500–600 |
| 正文 / 表单值 | 15px / 1.6 | 15px / 1.6 | 400 |
| 导航 / 按钮 | 13–14px / 1.4 | 14px / 1.4 | 500 |
| 辅助元数据 | 12px / 1.5 | 12px / 1.5 | 400–500，避免全大写长句 |

仅用 400 / 500 / 600 三档。大标题不用 800/900 超粗；主标题与正文的体积比约 3.2:1。表单可读性优先，不让所有正文降到 12px。时间、镜头序号可用 tabular-nums，整站不切换成等宽字体。

### 3. 页面与留白

- 1440px 视口使用最大 1200px 内容宽度，两侧约 120px；1280px 下使用 48px 边距；小于 768px 保持 20px。不要同时保留宽黑侧栏和窄工作区。
- 顶部 64px 高，logo 左对齐；中央 3 个页面入口；右侧项目状态和新建。当前导航用深文字和 1px 短下划线，避免大色块菜单。
- 导航到主标题至少 64px；主标题到说明 16px；说明到工作区 40px。区块间 40–48px，字段间 20–24px，同类标签到控件 8px。
- 统一 8px 节奏；输入/按钮圆角 8px，参考图 6px，大面板最多 12px，避免每个容器都 20px 巨圆角。
- 默认不加阴影。只有悬浮菜单/对话框使用低对比小阴影，帮助表达层级。

### 4. 第一页：输入主题与参考

- 标题建议：中文「从一个念头，到一场好戏。」或更直接「把灵感，变成可拍的故事。」；英文只留短小副标 `A studio for your next story.`，不把 UI 强行全英文。
- 工作区 2:1 双列：左侧主题与创作参数，右侧人像/服装/风格参考。主输入高度约 240px，字体 16px，标签写「故事主题或大纲」，示例仅一段自然文本。
- 四种产出使用一行紧凑单选：角色资产 / 道具资产 / AI 提示词 / 完整一套。单项图标 18–20px、标题 14px、说明一行 12px；不要四个大彩色宣传块。
- 参考图区按角色身份、人像服装、视觉风格分组，上传区灰底细虚线；已有参考用 80×96 或 96×96px 缩略图，不用多行长免责声明盖住图片。
- 人像参考与服装参考仍须分开标记；这是业务必要区分，可以用小标签表达。默认留 2–3 个位置，上传后再显示删除/替换。
- 「演示模式 · API 待接入」放在工作区标题或按钮边的短状态条；长技术解释放折叠「接入说明」。状态必须真实，但无需每个卡片重复。
- 全页只突出一个主按钮，约 44px 高，文案随模式变化；示例输入用下方文字链接。

### 5. 第二页：视频模型与输入

- 延续同一白色顶栏，不突然切成另一套深色视频软件。页首仅返回创作、项目标题、步骤 `02 / Video studio`。
- 左侧 280–320px 为模型/参数，右侧为提示词编辑器与参考条。模型选择使用整齐列表，每行一个小型单色图标、模型名称、短能力；选中行浅灰底。
- 默认 Seedance 2.5，其余型号同层级；供应商颜色只允许 4px 状态点或小图标，不作为整个列表的底色。Sora 2 作为禁用历史行，直接写已停服。
- 提示词编辑器约 420px 高，长文本 14–15px / 1.75，保留清楚镜头时间标记。段落预览与 JSON 请求分开切换，默认先显示人可读提示词。
- 下方采用一条紧凑参数栏：任务类型、画幅、分辨率、时长。模型改变后不支持的值立即重置/提示。
- 主按钮写「保存视频草稿」或「导出请求」，旁边短句「视频 API 待接入」。实际接入后再改为「生成视频」；不能用虚假进度让白色精致页面掩盖真实状态。

### 6. Logo 的精度检查

- 品牌写法固定 `Central.ai`；不要出现 `CENTRAL.AI`、`Central AI` 与 `central.ai` 混排在不同主位置。
- 推荐独立单色符号 + 字标，符号视觉高度 24px，间距 8px，字标字形与同一基线协调。若自绘 C 形符号，曲线必须为连续 Bézier、笔画厚度一致，开放口与字母 C 的方向清楚。
- 字标可使用经许可字体后转路径，避免不同系统字体造成 Central 与 .ai 宽度漂移；未转路径时只使用固定已加载字体，不能用 CSS 单独缩放 `.ai` 造成基线断裂。
- icon 用固定 viewBox，等比缩放，固定浅底和深底版本；不依赖 emoji、字符拼贴或 font-awesome 的通用火花图标。
- 16px favicon 允许重绘简化细节，不能仅把复杂 24px 标压缩到 16px。检查 16、24、32、48px 四种尺寸边缘与开口是否清楚。
- 内联图标统一 20px，1.5px 描边，圆角与端点一致；选中小勾与导航图标不要混进 2.5px 粗笔画。

## 验收重点

1. 首屏只存在一个明显主动作，输入框能在约 900px 高视口内看到；没有大段宣传抢占工作区。
2. 页面至少 85% UI 区域保持白/浅灰，视觉彩色主要来自参考图；细边框能区分输入但不制造表格般拥挤感。
3. 主标题、导航、字段、元数据只有上述层级；同类模块拥有相同对齐与间隔。
4. 项目卡片、参考图、结果图尺寸统一；图下文字最多两级，图片本身是重点。
5. 390px 宽下仍能完成大纲→参考→模式→进入工作室；主动作触达高度至少 44px，无横向溢出。
6. 原功能/交付边界保持：角色四视图、锁定对白、30 秒母场、模型限制、草稿导出全部可用；视觉研究不能以删去核心步骤换取空白感。
