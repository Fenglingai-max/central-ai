# Central.ai 品牌基础规范

## 符号：Open Gate

原创几何符号将 C 转译为开放的取景框。上下两片镜像结构围绕同一中心，左侧的细小断口形成水平光学轴，右侧开放口连接创意输入与影像输出。它也可被理解为两条围绕共同项目协作的创作轨道。

标记不依靠星形、渐变、发光或 AI 图标才能成立。主形状由两条 SVG 几何路径组成，透明背景，单色使用。

- 独立符号：`public/brand-mark.svg`，40 × 40 设计网格。
- 横向组合：`public/brand-lockup.svg`，199 × 48 设计网格。
- 纯字标：`public/wordmark.svg`，148 × 48 设计网格。
- 核心形状实际位于 x=4…35.525、y=4…36；左侧断口高 4 单位，主体厚度 7 单位。
- 上下结构必须整体等比缩放，保持中轴对称，不单独调整切口。

## 色彩与空间

- 主色为墨黑 `#111111`，背景为白 `#FFFFFF`。
- 次级界面灰可用 `#6B6B6B`、`#F4F4F2`；主标记优先纯黑或纯白。
- SVG 使用 `currentColor`。内联 SVG 可直接继承 CSS 的 `color`；作为 `<img>` 使用时默认黑色，深色背景可通过 CSS `filter: invert(1)` 反白。
- 最小独立符号尺寸 24 × 24 px，推荐导航中使用 32 × 32 px；小于 24 px 时不使用完整字标。
- 四周至少保留主体厚度（设计网格中的 7 单位）作为净空。
- 横向字标最小显示宽度 145 px，推荐导航中 174–200 px。

## 字标与排版

字标使用 Rasmus Andersson 设计的 **Inter Variable 4.001**，从随项目保存的官方 `public/InterVariable.woff2` 实例化为 `wght=570`、`opsz=32`，以 37px 字号绘制。文字已转换为精确 SVG 轮廓路径，不含 `<text>`，不依赖操作系统字体、网页字体加载顺序或字体回退，跨平台外观一致。

使用 HarfBuzz 保留 Inter 原生字偶间距，再施加 -1.45px 的整体字距，并对相邻字偶作 ±0.02…0.22px 的光学校正。字标净推进宽约 145.986 设计单位；`.ai` 保持为名称的一部分，不另作徽章。正式写法为 **Central.ai**，C 大写，其余小写。

横向组合中符号与文字保持独立净空；符号负责识别，字标负责清晰，不在其周围添加边框、星星或光效。

页面建议采用白底、较大留白和细灰分隔线。网页英文采用项目内的 Inter Variable，中文使用系统无衬线（PingFang SC / Noto Sans SC）。标题使用中等字重与略收紧字距，正文保持正常字距；避免全站过粗或过大的文字。

## 文件与许可

- Open Gate 符号路径为本项目原创。
- Inter 字体及字标轮廓来自 Rasmus Andersson 的 Inter Variable，采用 SIL Open Font License 1.1。官方字体许可保存在 `public/INTER-LICENSE.txt`。
- 横向组合与纯字标均保留 `<title>`、`<desc>` 及 `role="img"`，图形以路径呈现。不要将轮廓转换后的 Logo 误作可选择文字；作为图片嵌入时提供 `alt="Central.ai"`。
- 生成工具：fontTools 4.68.0（变量字体实例化、SVGPathPen 轮廓输出）及 HarfBuzz / uharfbuzz 0.57.0（原生 kerning 排版）。工具与临时实例字体均留在工作目录，未加入网页包。
